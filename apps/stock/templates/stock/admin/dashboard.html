앱 페이지 관리

아직 준비되지 않은 기능입니다.

AiStockQuote는 실시간 시세 데이터를 외부 API(yfinance)에서 그때그때 가져와 보여주는 앱이라, 관리자가 직접 편집하는 페이지/콘텐츠가 없습니다.

문구관리

아직 준비되지 않은 기능입니다.

화면 문구는 현재 템플릿에 직접 두고 있어, 별도의 문구관리 화면이 아직 없습니다.

약관관리

회원가입 동의 항목(이용약관/개인정보처리방침/AI 서비스 이용안내는 필수, 마케팅수신동의/위치정보이용약관은 선택)을 관리합니다. 각 항목은 게시 여부·필수/선택 여부를 따로 켜고 끌 수 있고, 별도 게시 URL(/stock/terms/<key>/)을 가집니다. 저장할 때마다 새 버전이 발행되고 이전 버전은 이력으로 남습니다.

API key 관리

시세 분석용 AI provider(Anthropic/OpenAI/Gemini)를 선택하고, provider별 사용여부/API key/모델/메모를 관리합니다. 저장 후 자동으로 실시간 검증하며, "키 검증" 버튼으로 언제든 다시 확인할 수 있습니다.

소셜로그인 연동 현황

카카오/네이버/구글/애플 회원가입·로그인 백엔드는 이미 구현되어 있습니다. 각 제공사 개발자센터에서 발급받은 클라이언트ID/시크릿을 아래에 입력하고 "사용"을 켜면 로그인/회원가입 화면에 해당 버튼이 나타납니다. 이 설정은 허브 전체 5개 서브앱(aura/stock/aerogo/origin)이 공유하며, 저장하면 재시작 없이 즉시 반영되고 .env에도 기록됩니다.

최근 소셜로그인 연동 계정

제공사이메일표시 이름연결된 회원최근 로그인
아직 연동된 소셜 계정이 없습니다.
