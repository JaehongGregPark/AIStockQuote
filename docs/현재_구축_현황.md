# 현재 구축 현황

기준일: 2026-08-03

## 프로젝트 구성

- `backend/`: 최신 Django 백엔드와 웹 화면
- `app/`, `static/`: 기존 FastAPI 백엔드와 정적 프론트엔드
- `tests/`: FastAPI 버전 테스트
- `backend/tests/`: Django 독립화 검증 테스트

## 구현된 기능

- KOSPI, KOSDAQ, NASDAQ, DOW 주요 종목 목록과 검색
- Yahoo Finance 기반 현재가·등락률·거래소·통화·차트 조회
- 병렬 조회, TTL 캐시, 일부 종목 실패 목록과 데이터 신뢰도 표시
- Anthropic, OpenAI, Gemini 기반 종목 분석과 제공자 설정·연결 점검
- 종목 비교, 관심종목, 최근 조회, 가격 알림
- 시장 이벤트, 종목 뉴스, GNews 설정과 데이터 품질 기록
- 자체 회원가입·로그인·로그아웃·탈퇴·프로필 관리
- 이메일 인증, 비밀번호 찾기/변경, 로그인 이력과 잠금 정책
- 카카오·네이버·구글·애플 소셜 로그인 연동 코드
- 약관 버전 관리와 회원 동의 이력
- 회원·콘텐츠·AI 공급자·뉴스 설정을 포함한 관리자 대시보드

## 데이터

IntegratedHub의 Stock SQLite 데이터와 마이그레이션 이력을 `backend/db.sqlite3`로 복사했다. 운영 PostgreSQL은 `POSTGRES_*` 환경변수와 `stock` 스키마를 사용한다.

## 독립화 변경

- IntegratedHub의 landing, DB 라우터, 공용 직원 SSO 의존성 제거
- 독립 Django 관리자 계정과 파일 기반 회원 인증 정책 사용
- Stock에 필요한 공용 소셜 로그인·뉴스 서비스만 포함
- `/stock/` URL과 기존 API 계약 유지
