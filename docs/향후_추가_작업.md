# 향후 추가 작업

## 전환 전 필수

- 운영 Stock DB 최종 덤프·복원 및 롤백 절차 확정
- HTTPS, CSRF, CORS, 허용 도메인과 비밀키 설정
- SMTP 및 소셜 로그인 콜백 URL을 새 도메인으로 등록
- AI·뉴스 공급자별 비용 한도, 타임아웃과 장애 대응 정책 설정
- 정적 파일, 로그, DB 백업과 복구 자동화
- 인증·관리자·시세·AI 분석 핵심 시나리오 회귀 테스트 보강

## 기능 개선

- 공식 또는 계약된 실시간 시세 공급자로 전환 검토
- 거래소 휴장·지연 시세·통화·기업행사 데이터 정확도 강화
- 가격 알림의 스케줄러와 실제 이메일/푸시 발송 구현
- 개인화 포트폴리오, 수익률 및 위험 분석
- 뉴스 중복 제거, 종목 연관도와 출처 신뢰도 평가
- 투자 판단이 아닌 정보 제공임을 명확히 하는 고지와 설명가능성 강화

## 운영 개선

- CI 마이그레이션 검사, 테스트, 정적 파일 빌드 자동화
- 독립 배포·모니터링·오류 추적·상태 확인 엔드포인트
- 개인정보 보존기간, 탈퇴 데이터 파기, 관리자 감사로그 정책
- 기존 FastAPI와 Django 중 장기 유지할 단일 런타임 결정
- IntegratedHub 전환 검증 후 Stock 등록·코드·DB·문서 제거
