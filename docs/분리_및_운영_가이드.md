# 분리 및 운영 가이드

## 개발 기준

회원·약관·운영 기능이 포함된 최신 Django 서비스는 프로젝트 루트를 기준으로 개발한다. 기존 FastAPI 구현은 `legacy_fastapi/`에 이력 참조용으로 보존한다.

## 운영 전환

1. 루트의 `.env.example`을 `.env`로 복사한다.
2. 운영 비밀키, 도메인, DB, SMTP, AI 공급자와 뉴스 API 설정을 입력한다.
3. `python manage.py migrate`와 `python manage.py collectstatic --noinput`을 실행한다.
4. `python manage.py createsuperuser`로 독립 관리자 계정을 만든다.
5. `/stock/`, 핵심 API, 관리자와 인증 흐름을 점검한다.

SQLite 파일은 분리 시점 스냅샷이다. 실제 전환 시 IntegratedHub Stock 쓰기를 중지한 뒤 운영 DB를 최종 덤프·복원해야 데이터 분기를 막을 수 있다.
